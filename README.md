# Ordway Table Width Extension [Archived]

Chrome extension that enhanced Ordway's table UI by providing custom width controls and persistent settings. Built to optimize data visibility in Ordway's billing platform (pre-2023 version).

## Purpose & Problem Solved

The original Ordway platform had fixed-width tables that didn't effectively utilize available screen space, making it difficult to view complete data entries. This extension:

- Added dynamic table width controls
- Preserved user width preferences via local storage
- Improved data visibility for wide-screen users
- Eliminated horizontal scrolling for most data views

## Technical Implementation

- Chrome Extension API
- JavaScript DOM manipulation
- Local Storage for settings persistence
- Custom UI controls for width adjustment

## Status

This extension is now archived as Ordway's platform upgrade in 2023 implemented proper responsive tables, eliminating the need for this solution.
